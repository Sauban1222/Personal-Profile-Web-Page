GIT COMMANDS — run these yourself in VS Code Terminal / PowerShell

1. Open terminal in this project folder:
   cd path\to\personal_profile_project

2. Initialize Git:
   git init
   git status

3. Add and commit:
   git add .
   git commit -m "Create personal profile web page"

4. Create an empty repository on GitHub, then connect it (replace USERNAME and REPO):
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPO.git
   git push -u origin main

5. For screenshots, capture:
   - terminal showing git init and git status
   - terminal showing git add / git commit and push success
   - GitHub repository page showing the uploaded files

If Git asks you to configure identity:
   git config --global user.name "Your Name"
   git config --global user.email "your-email@example.com"

Do not use placeholder USERNAME, REPO, or email in your final submission.
