# Personal Profile Web Page — DigiSkills Hands-on Exercise 1

## Files
- `html-only.html`: Question 1, Part 1 (HTML-only version).
- `index.html` and `style.css`: Question 1, Part 2 (styled and responsive version).

## Before submitting
1. Replace `your-email@example.com` with your real email address in both HTML files.
2. Check the name and profile text and personalize them so the submission reflects your own work.
3. Open `html-only.html` in a browser and capture a screenshot of the page and its code.
4. Open `index.html` in a browser and capture a screenshot of the styled page and its code.
5. Follow the Git steps in `GIT_STEPS.txt` and capture screenshots of your own terminal and GitHub repository.
6. Insert your screenshots into one Word document (.docx). The exercise asks for screenshots of each step; this package does not fabricate screenshots of commands or a GitHub upload.

## Run
Double-click `html-only.html` or `index.html` to open it in your browser.
